# Multi-Vendor E-Commerce Platform

A full-stack MERN multi-vendor e-commerce platform that allows multiple sellers to manage their stores and products while customers can browse products, place orders, and make secure payments.

## Features

- User authentication and authorization
- Customer and seller accounts
- Multi-vendor store management
- Product listing and management
- Product categories and search
- Shopping cart and wishlist
- Order management and tracking
- Secure payment integration
- Admin dashboard and vendor management
- Responsive user interface

## Tech Stack

**Frontend**
- React.js
- Material UI
- Redux Toolkit
- TanStack Query

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose

**Other Tools**
- JWT Authentication
- REST APIs
- Git & GitHub

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Jibran-shah/multi-vendor-ecommerce.git
cd multi-vendor-ecommerce
```

### 2. Install dependencies

```bash
cd backend
npm install

cd ../frontend
npm install
```

### 3. Configure environment variables

Create `.env` files in the required directories.

Refer to `.env.example` files for the required environment variables.

### 4. Run the application

Start the backend:

```bash
cd backend
npm run dev
```

Start the frontend in another terminal:

```bash
cd frontend
npm run dev
```
